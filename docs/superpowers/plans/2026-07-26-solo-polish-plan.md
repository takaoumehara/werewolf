# ソロAIモード磨き込みプラン (2026-07-26)

ユーザー実プレイ(本番 jinro-bb5a5.web.app)のフィードバックに基づく改善。branch: mobile-ui-design-system。

## 診断（確定）

| 症状 | 原因 | 修正 |
|---|---|---|
| 一晩で人狼勝利 | `computeDefaultComposition` が人数無視で狼2固定。5人+夜先行+パリティ勝利(`wolves>=citizens`)で初夜即決着 | 狼数を人数でスケール(5-6人:1, 7-9人:2, 10人+:3) |
| AIが一度も発話しない | 上記により昼フェーズが一度も発生せず。LLM経路は未検証のまま | バランス修正で昼到達。＋本番キーの疎通スモーク |
| 「参加 8人」表示 | デモ固定配列 `PLAYERS.length` がライブの構成画面に漏れ | ライブ時は実ロスター数を表示 |
| カード頭切れ | `.roster-thumb img { height:130%; bottom:-2px }` 上30%を切る実装 | バリエーション提示→ユーザー選択で置換 |
| カード小さい | `.roster-grid` 4列固定 | 人数適応グリッド(5人→2-3列大判) |
| 役職が3種のみ | MVP1 AI brain が citizen/prophet/werewolf のみ対応(意図的クランプ) | 次弾: bodyguard(騎士)AI追加で4種に |
| 「卓のバランス」が難語 | コピー | 「役職の人数を調整します」等へ |
| 最初の画面に戻れない | リセット導線なし | 終幕/設定に「タイトルに戻る」追加 |
| 自分の役職を再確認しづらい | 長押しピークのみ | 常設ボタン+フルスクリーンカードビューア |

## ワークストリームとモデル割当

- **A. 本体修正**(バランス/表示/コピー/リセット/フルスクリーン役職カード): Fable 5 直接(mobile_app.html 直列編集で競合回避)
- **B. カード表示バリエーション**: Sonnet 5 サブエージェント → モックHTML+スクショ4案 → ユーザー選択後に本実装
- **C. サウンドエンジン**: Sonnet 5 サブエージェント → typespace方式(Web Audio・決定論・3バス・素数周期・微小ゲイン)を人狼向けに移植した独立モジュール `game-client/sound-engine.js` + 試聴ページ。配線は選択後
- **D. レビュー**: Opus 5(デプロイ前)
- **E. 騎士AI追加**: 次弾(decideNightAction に guard 分岐、決定論なのでLLM不要)

## サウンド設計方針(typespace文書からの適用)

- 音源ファイル不要。Web Audio APIのみ、リバーブIRもコード生成
- フェーズ→空気(air): night=inward(低)、day=calm、vote=open寄り+シマー密度増(緊張)、finished=解決和音
- スティンガー: 襲撃(鐘・非整数倍音)、処刑、役職公開、勝利(陣営別)
- 決定論: Math.random禁止、seededUnit方式。ゲイン0.01-0.05、コンプレッサ終段
- iOS: ユーザー操作内で resume()。ミュートトグルをトップバーに(既定ON=消音でも可)
