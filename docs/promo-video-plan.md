# プロモ動画 — 構成表とプロンプト集

> Written by: superforge · 2026-08-02
> 対象: 『月下ノ影 — GEKKA / SHADOWS』のポートフォリオ公開用プロモ動画

## この文書の使い方

**この環境からは動画を生成できない**（KIE.AI の鍵が無く、プロキシ経由でも `api.kie.ai` に
到達できない）。だからここには「生成の代わり」ではなく、**あなたがブラウザで実行するための
台本とプロンプトそのもの**を置いてある。上から順にコピーして貼れば1本できる。

生成にかかる費用を先に書く。**0円で作れる案（案A）を先に置いた。**

---

## 0. 先に決めること — 誰に何を見せる動画か

| | 案A: 実画面だけ | 案B: 実画面 + AI生成カット |
|---|---|---|
| 費用 | **0円** | 約 1,500〜4,000円（下の見積り） |
| 制作時間 | 1〜2時間 | 3〜5時間 |
| 向く相手 | 採用担当・エンジニア・「動くのか」を見たい人 | 一般・SNS・「面白そうか」を見たい人 |
| 弱点 | 世界観の入りが弱い | 実物より良く見えて期待値がずれる |

**推薦は案A。** 理由は、この作品の強みが「24枚の絵札」と「実際に遊べること」であって、
AI動画はその両方より弱いから。生成カットを足すなら**冒頭5秒だけ**にする。

残す: 1 → 4 → 5 → 7 → 8 → 10。
落とす: 2（参加導線）、3（構成）、6（AI）、9（グリッド）。
**カット4（長押しで役職が開く）は絶対に落とさない。** ここがこの作品でいちばん「触りたくなる」瞬間。

## 2. 実画面の撮り方（案A・0円）

### 撮る前に
```
1. Chrome を開き、幅 393 / 高さ 852 でデバイスツールバーを出す
   （実機で撮るなら iPhone の画面収録が最も楽で、いちばん綺麗）
2. localStorage を消す（遊び方の説明を初回状態から見せるため）
   DevTools → Application → Local Storage → gekka-howto-seen を削除
3. 音は必ずオンにする（トップバーの「♪ オフ」を押して「♪ オン」にする）
4. 「ひとりで遊ぶ（AI対戦）」で 5人卓を立てる。撮影が最短で済む
```

### カットごとの操作
| # | 操作 | 撮影のコツ |
|---|---|---|
| 2 | s03 の合言葉画面 → s04 で名前を入れる | 文字入力は等速でなく、**打ち終わりだけ**見せる |
| 3 | s07 で下へゆっくりスクロール → 絵札を1枚タップ | スクロールは**1秒に1行**。速いと絵が読めない |
| 4 | s09 の封蝋を長押し → 2秒見せて離す | **離す瞬間まで撮る。** 隠れるところが売り |
| 5 | s11 で相手を1人選ぶ | 選択の枠が光る瞬間で止める |
| 6 | s14 でチャットに1言入れて、AIの返事を待つ | AIの返事は数秒かかる。**待ち時間はカットで詰める** |
| 7 | s15 で投票 → s17 の評決 | 生存者ストリップから名前が消えるのを必ず入れる |
| 8 | s18 で絵札をタップして全画面 | ここだけ 1.5倍にスローにすると効く |
| 9 | 図鑑タブ（ルール → 図鑑）を高速スクロール | 2倍速で流す |

### 編集
- **無料で足りる**: DaVinci Resolve（無料版で全部できる）／ CapCut ／ iMovie。
- 書き出し: H.264 / 縦 1080×1920 / 30fps / 8Mbps。**60秒で 6〜8MB** に収まる。
- 文字は**画面の下 1/4 に固定**。UIの上に重ねない（読めなくなる）。
- フォントは本文に合わせて Noto Serif JP の Bold。

### 音（0円）
アプリの生成音をそのまま録る。**画面収録に内部音声を含める**のがいちばん整合する。
外部BGMを足すと、アプリの音と喧嘩するうえ商用利用の確認が別途要る。

## 3. AI生成カットのプロンプト（案B・冒頭と締めだけ）

> 生成するのは **カット1（0–3.5秒）と カット9の背景（50–56秒）だけ**にする。
> 実画面より綺麗な架空の映像を並べると、実物を見たときの落差が作品の評価を下げる。

### 生成の前提（すべてのプロンプトで共通）
世界観は `world-theme.md` の正本に従う。**新しい設定を足さない。**

```
共通スタイル指定（全プロンプトの末尾に貼る）:
Style: post-apocalyptic dark fantasy, retro-futuristic medieval fused with gothic
graphic novel. Ruined megastructures of a lost high civilization reused as city
walls. Lantern-lit, low-key lighting, deep shadows. Muted sepia, soot green,
dull blue, dim amber lantern glow. Moonlight as the only cool light source.
No text, no logos, no watermarks, no on-screen UI.
Camera: slow, heavy, deliberate. No fast cuts, no whip pans.
```

### カット1 — ロゴが浮かぶ前の3.5秒

**Kie.ai / Veo 系 (text-to-video)**
```
A single oil lantern hanging in absolute darkness, its flame breathing and
guttering. The light reveals only fragments: wet cobblestones, the base of a
colossal ruined tower, mist drifting low across the ground. The camera pushes
in very slowly, 3 seconds, almost imperceptible. Nothing else moves. Cold
moonlight bleeds in from the upper left, never reaching the lantern.
Aspect ratio 9:16. Duration 4s. 24fps, cinematic.
[共通スタイル指定を貼る]
```

**Higgsfield（image-to-video で確実性を上げる場合）**
1. まず静止画を作る（`generate_image` か Midjourney）:
```
A single oil lantern in absolute darkness, wet cobblestones, the base of a
colossal ruined tower behind it, low drifting mist, cold moonlight from upper
left. Vertical composition 9:16. Painterly, gothic graphic novel.
[共通スタイル指定を貼る]
```
2. その画像を Higgsfield に入れ、モーションを指定:
```
Motion: very slow dolly-in. Flame flickers irregularly. Mist drifts left to
right. Everything else static. 4 seconds. No camera shake.
```

### カット9 — 絵札グリッドの背後に流す背景

```
An empty stone council chamber at night, seen from above. A long wooden table,
24 face-down cards laid out in a grid, lit only by candles at the edges of frame.
The camera drifts slowly upward. Dust motes in the air. Nobody present.
Aspect ratio 9:16. Duration 6s.
[共通スタイル指定を貼る]
```

### やってはいけないこと
- **人狼や役職キャラクターを AI 動画で作らない。** 24枚の絵札が正本であり、
  動画で別デザインの人狼が出た瞬間に世界観が二重になる。
  キャラクターを動かしたいなら `videos-72/werewolf_char_green_loop.mp4` を使う（既にある）。
- **UI を含む映像を生成しない。** 架空のUIが出る。実画面を撮る。
- 生成物に文字を入れさせない。日本語は必ず崩れる。文字は編集で載せる。

### 費用の見積り（2026-08 時点の一般的な相場・実費は各サービスで要確認）
| 用途 | 本数 | 目安 |
|---|---|---|
| カット1（4秒）| 失敗込みで4〜6本 | 約 800〜2,000円 |
| カット9（6秒）| 失敗込みで3〜4本 | 約 700〜2,000円 |
| **合計** | | **約 1,500〜4,000円** |

生成系は**1本目で当たらない前提**で見積もること。同じプロンプトで3本引くより、
プロンプトを1行ずつ変えて引いたほうが当たる。

### 商用利用の確認（公開前に必ず）
- 使うサービスの利用規約で**生成物の商用利用が許諾されているか**を確認する。
- **人物の顔を生成しない**（実在人物への類似が争点になり得るため）。上のプロンプトは
  意図的に人を含めていない。
- 生成物を `design/` に最終素材として置かない。置くのは編集済みの完成動画だけ。

## 4. 横位置（16:9）が要るときの差分

| 変える所 | 内容 |
|---|---|
| 実画面カット | 端末フレーム付きのデスクトップ表示（1440×900）で撮り直す。左右のサイドバーごと入れると「大画面でも成立する」ことが伝わる |
| カット1・9 | プロンプトの `Aspect ratio 9:16` を `16:9` にし、`Vertical composition` を `Wide composition` に変える |
| 文字位置 | 下 1/4 → 左下 1/3 に寄せる |

## 付録: この動画で見せない方がいいもの

- **ルーム番号の期限切れ**（TTL 5分）— 途中復帰できないので、長い撮影では必ず切れる。
  録り直しになるため、卓を立ててから10分以内に撮り切る。
- **AIの発話待ち**（数秒かかる）— そのまま入れると停滞して見える。必ず詰める。
- **決選投票**（未実装）— 同数になったら「処刑なし」で進むので、
  同数になる卓を撮らない。
